# セキュリティポリシー / Security Policy

## サポート対象バージョン / Supported Versions

サポート対象は最新版のみです。旧バージョンへの修正の提供は行いません。

Only the latest version is supported. Fixes are not provided for older versions.

| バージョン / Version | サポート状況 / Supported |
| -------------------- | ------------------------ |
| 最新版 / Latest      | :white_check_mark:       |
| 旧バージョン / Older versions | :x:               |

## 脆弱性の報告方法 / Reporting a Vulnerability

脆弱性を発見した場合は、GitHub の [Issues](../../issues) からご報告ください。

If you discover a vulnerability, please report it through [GitHub Issues](../../issues).

内容を確認し、修正が必要と判断した場合はアップデートを公開します。

We will review each report and release an update if a fix is deemed necessary.

---

報告は日本語・英語どちらでも受け付けています。

Reports are accepted in both Japanese and English.
